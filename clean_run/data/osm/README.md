# OSM Attraction Expansion Data

This folder contains OpenStreetMap-derived attraction expansion candidates for TourUni.

## Files

- `osm_attraction_candidates.json`  
  Full normalized candidate dataset in the same district-based shape as `sri_lanka_attractions.json`, with extra OSM review fields.

- `osm_attraction_review.csv`  
  Human-review spreadsheet. Edit `review_status` to `approved`, `keep`, or `osm_verified` to promote a candidate later.

- `expanded_sri_lanka_attractions.json`  
  Safe merge output generated by `merge_reviewed_osm_attractions.py`. With the current unreviewed CSV it intentionally contains only the original curated 351 attractions.

- `osm_attraction_summary.json`  
  Counts and output paths from the latest build.

- `raw_overpass/`  
  Cached raw Overpass responses per district, so reruns do not repeatedly hit the public Overpass API.

## Rules

Do not point the planner directly at raw OSM candidates.

Use this flow instead:

1. Build candidates:
   `python clean_run/scripts/build_osm_attraction_candidates.py`

2. Review `osm_attraction_review.csv`.

3. Mark good rows as `approved`, `keep`, or `osm_verified`.

4. Merge reviewed rows:
   `python clean_run/scripts/merge_reviewed_osm_attractions.py`

5. Only then consider replacing the planner attraction file with the expanded output.
